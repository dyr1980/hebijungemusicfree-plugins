## 3. 音频资源规律

- **直链 URL 模板**
  ```
  https://cdn.dj1198.com/uploads/play/128k/<YYYYMMDD>/<32位十六进制哈希>.mp3
  ```
  - `128k`：码率目录（当前仅确认 128k；尝试 `320k` 返回 **404**，故更高码率未开放）
  - `<YYYYMMDD>`：上传日期（如 `20260806`）
  - `<hash>`：文件 MD5 类哈希（32 位 hex），与歌曲一一对应
- **CDN 域名**：`cdn.dj1198.com`（音频 + 图片同域不同路径）；封面兜底走 `play.dj1198.com`
- **格式**：**仅 mp3**（全站未发现 `.m4a`/`.aac`/`.flac`/`.m3u8`）；码率 128k
- **是否全站同源**：**否**。主站 `dj14.com` 与音频 CDN `cdn.dj1198.com` 不同源，音频为独立 CDN
- **是否带签名/过期**：**否**。URL 为纯静态路径，无 token / exp / sign 参数，可直接长期引用
- **文件体积**：实测单曲约 **88.7 MB**（88,721,987 字节），属较大文件，需流式/Range 播放

## 4. 播放流程（请求链）

打开某首歌到出声，浏览器依次发起：

1. `GET http://dj14.com/music/<id>.html`
   - 服务端返回完整 HTML，内含：
     - 内联播放列表 JSON：`[{"title":..., "mp3":"https://cdn.dj1198.com/uploads/play/128k/...mp3", "id":..., "cover":...}, ...]`
     - 当前曲目 `mp3` 字段**已填好直链**；其余曲目 `mp3` 为空 `""`
     - 播放器脚本 `<script src="/resources/web/dj82/assets/82dj/js/player_adapted.js">`（QPlayer）
2. 加载依赖脚本/样式：`jquery.min.js`、`player_adapted.js`、`swiper.min.js`、`layer.js`、CSS（约 21 个 script / 20 个 stylesheet）
3. QPlayer 读取内联列表，将当前曲直链赋值给 `<audio>` 的 `src`
4. 用户点击播放 → `GET https://cdn.dj1198.com/uploads/play/128k/<date>/<hash>.mp3`
   - 请求带 `Range: bytes=0-`（断点续传/拖动进度），CDN 返回 `206 Partial Content`

**是否需解密/签名/额外渲染**：当前曲目**不需要**——直链直接写死在页面 HTML 里，浏览器原生 `<audio>` 即可播放，无 JS 解密、无 token 校验、无二次取链 API。
（其它曲目若 `mp3` 为空，切歌时可能触发一次取链请求，本次未捕获其端点；集成时可只依赖当前曲内联直链。）

## 5. 反爬 / 校验机制

| 校验项 | 实测结论 |
|--------|----------|
| eval 混淆写 Cookie | **未发现**。首页与音频直链用纯 GET + 普通桌面 UA 即可拿到，无需任何 Cookie |
| Referer 校验（音频） | **无**。不带 Referer 直接 `curl` 音频直链返回 `200`（见第 6 节）；带 `Referer: http://dj14.com/` 同样 `200` |
| CORS 限制 | 对 `<audio>` 播放无影响（媒体元素默认不受 CORS 限制，除非显式加 `crossorigin`）；未观察到跨域拦截 |
| Range / 断点续传 | **支持**。`Range: bytes=0-1023` 返回 `206`，`Accept-Ranges: bytes` |
| UA 限制 | 普通桌面 Chrome UA 正常工作，未观测到 UA 封锁 |
| 登录态 | 存在用户系统（`/user/join.html`），但**播放/取直链均不需登录** |
| 总结 | 反爬门槛极低，几乎等于「静态资源直链」。直接 `curl` 即可获取音频内容 |

## 6. 可访问性测试结论（重点）

对真实捕获的音频直链做 curl 实测（均加 `-k`，桌面 UA）：

```bash
# 直链（不带 Referer）
URL="https://cdn.dj1198.com/uploads/play/128k/20260806/1913efddb155c455d14f976fcce94c72.mp3"

# 1) 无 Referer HEAD
curl -k -s -I -A "Mozilla/5.0 ... Chrome/120" "$URL"
# → HTTP/1.1 200 OK  (audio/mpeg，可访问)

# 2) 带 Referer 完整头
curl -k -s -I -e "http://dj14.com/" "$URL"
# HTTP/1.1 200 OK
# Server: nginx
# Content-Type: audio/mpeg
# Content-Length: 88721987
# Accept-Ranges: bytes

# 3) Range 断点
curl -k -s -e "http://dj14.com/" -H "Range: bytes=0-1023" -o /dev/null -w "status=%{http_code} rlen=%{size_download}\n" "$URL"
# → status=206  rlen=1024   (支持 Range 拖动)
```

| 测试项 | 结果 |
|--------|------|
| HTTP 状态码 | **200**（无 Referer 也 200） |
| Content-Type | `audio/mpeg` |
| Content-Length | 88,721,987（约 88.7 MB，真实 mp3） |
| Accept-Ranges | `bytes`（支持断点/拖动） |
| Range 请求 | `206 Partial Content`（正常） |
| Referer 防盗链 | **无**（不带 Referer 仍可下） |
| DNS 可达 | `cdn.dj1198.com → 60.174.238.119` 正常解析 |
| 320k 高码率 | 404（仅 128k 开放） |

**结论：现在能播放。** 音频 CDN `cdn.dj1198.com` 当前 DNS 正常、直链可直接访问、无 Referer/Cookie/签名校验、支持 Range；与曾因 CDN DNS 失效而全站瘫痪的 72dj.com 不同，dj14 当前音频链路健康。

## 7. 给 DJ 播放器项目（AjunDJ）的接入提示

1. **拿直链最稳的办法**：直接 `GET /music/<id>.html`，从页面内联 JSON 中提取 `"mp3":"https://cdn.dj1198.com/uploads/play/128k/...mp3"`（正则提取即可），**无需任何 API Key / 登录 / Cookie**。
   ```python
   import re, requests
   html = requests.get(f"http://dj14.com/music/{song_id}.html",
                       headers={"User-Agent":"Mozilla/5.0"}).text
   m = re.search(r'mp3\\":\\"(https://cdn\.dj1198\.com/uploads/play/128k/[^\"]+\.mp3)', html)
   audio_url = m.group(1).replace('\\/','/') if m else None
   ```
2. **列歌单**：`GET /search?keys=<词>` 或 `/genre/c<N>.html`，解析出 `/music/N.html` 链接（搜索结果页实测含 20 个单曲链接），再逐页取直链。
3. **播放器对接**：把直链直接喂给 `<audio>` / ExoPlayer / AVPlayer；CDN 支持 `Range`，可正常seek；文件较大（~88MB），建议开启流式缓冲。
4. **无需防盗链处理**：实测不带 Referer 也能播；为礼貌/稳妥可带 `Referer: http://dj14.com/`，但**不是必须**。
5. **注意点**：
   - 仅 128k mp3，音质固定；不要拼 `320k` 路径（404）。
   - 音频与站点**不同源**，依赖单一 CDN `cdn.dj1198.com`——若将来该 CDN 出现类似 72dj 的 DNS 失效，全站将不可播；接入时建议对 `cdn.dj1198.com` 做可达性监控/兜底。
   - 列表中非当前曲目的 `mp3` 字段为空，若要做「一键播放整张歌单」，需进一步确认切歌取链接口（本次未捕获），否则逐曲打开 `/music/<id>.html` 取直链即可。
   - 搜索联想接口 `/search/selbox/`（POST `q=`）可作输入框自动补全增强，但非播放必需。
6. **合规**：仅作在线试听/个人使用；注意站点版权与下载条款（`/servers/copyright.html` 等）。
