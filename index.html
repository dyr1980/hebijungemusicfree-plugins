🌀 澜音（CeruMusic）v2 插件 · MusicFree 适配版 57 个

由本仓 57 个 MusicFree 插件适配为澜音 v2 原生 artifact，搜索 / 取链 / 歌词沿用原插件实现。

插件清单 · 仅供查看 https://gh.padao.fun/https://raw.githubusercontent.com/hebijunge/musicfree-plugins/master/ceru-plugins.json

⚠️ 这是展示用的 JSON 清单，不能导入澜音；粘贴到「从链接添加音源」会报 Expected exports.manifest。请复制下方插件卡片里的「加速直链」，一条链接对应一个插件。

安装方法：
· 澜音 CeruMusic：插件管理 → 添加插件 → 粘贴下方任一插件的 加速直链，或下载 .js 后从文件导入；
· 首次启用授予 network（网络访问）权限；
· v2 artifact 不是订阅清单，一次导入一个插件。

搜索 / 取链 / 歌词沿用原 MusicFree 插件实现，网络统一走宿主 core.http.request 代理；榜单映射到 charts，歌单导入（importMusicSheet）已桥接为 playlistImporters，LRC 歌词转成毫秒时间轴。

⚠️ 澜音 v2 artifact、LX 自定义源、MusicFree 插件是三套互不通用的协议，请在对应播放器的插件入口安装。超大插件（agg）采用精简构建，以满足澜音 50 万 AST 节点上限。

🎼 洛雪（LX）自定义源 · 多播放器通用 v1.6.0

五源合一 LX 格式自定义源脚本，适用于所有支持洛雪(LX)插件协议的播放器（洛雪、澜音 CeruMusic 等）。非订阅机制、一次导入一个脚本，导入后不会随清单自动更新。

五源合一(LX) · 导入链接 · v1.6.0 https://hebijunge.github.io/musicfree-plugins/plugins/five-source-lx.plugin.v1.6.0.js

导入方法：
· 洛雪 Music：设置 → 自定义源管理 → 导入，选「在线链接」粘贴上方地址，或下载 .js 后选「本地文件」导入；
· 澜音 CeruMusic：插件管理 → 添加插件 → 粘贴上方「在线导入链接」或选择本地 .js 导入，首次启用授予 network（网络）权限即可。
导入成功后在对应播放器音源处切换即可。

⚠️ 这是 LX（洛雪）格式脚本，不是 MusicFree 原生插件，无法在 MusicFree「插件订阅」里直接安装；请在对应播放器的自定义源 / LX 导入入口使用。
