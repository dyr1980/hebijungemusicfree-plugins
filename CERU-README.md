# 澜音（CeruMusic）插件 · MusicFree 适配版

> 由 `hebijunge/musicfree-plugins` 的 57 个 MusicFree 插件适配为澜音 v2 原生插件；搜索、取链、歌词、榜单沿用原插件实现。

## 安装

1. 打开澜音 → 插件管理 → 添加插件，粘贴下表中某个插件的 **加速直链**。
2. 或点击直链下载 `.js`，用「从文件导入」。
3. 首次启用授予 **network（网络访问）** 权限。

> 国内网络请勿直连 `raw.githubusercontent.com`（常被重置），请使用下表的加速链接。

## 说明

- 搜索 / 取链 / 歌词来自原 MusicFree 插件，网络经澜音宿主代理，遵守澜音沙箱安全策略。
- 榜单（getTopLists）在多数插件上可用；歌单/专辑导入（importMusicSheet）已在 26 个插件上支持。
- `ceru-plugins.json` 是展示清单，**不是澜音订阅格式**，不能直接导入；请导入单个 `.js` 插件。
